# Учись сам: каталог курсов

Учебная веб-страничка с каталогом курсов для самостоятельного обучения.

- поиск по курсам, фильтр по направлению и уровню;
- кнопка «Начать» добавляет курс в «Мои курсы»;
- прогресс по урокам сохраняется в браузере (localStorage);
- светлая и тёмная тема, работает на телефоне.

## Как открыть

Откройте `index.html` в браузере или включите GitHub Pages
(Settings → Pages → Deploy from a branch → `main` / `root`).

## Как добавить курс

Допишите объект в массив `COURSES` в файле `script.js`.
